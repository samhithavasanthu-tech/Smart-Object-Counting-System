
# Smart Real-Time Object Detection and Counting System

## Project Overview
This project detects and counts objects in real time using computer vision and deep learning. It uses YOLOv8 for object detection and ByteTrack for object tracking.

## Technologies Used
- Python
- YOLOv8
- OpenCV
- ByteTrack
- NumPy

## Features
- Real-time object detection
- Multi-class object recognition
- Object tracking with unique IDs
- Upward and downward counting
- Virtual counting line
- Class-wise counting
- FPS display
- CSV logging with timestamps
- Reset counter
- Live webcam interface

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the project:

   python object_detection.py

## Controls
- R - Reset counting
- Q - Quit application

## Output
The system displays detected objects, bounding boxes, tracking IDs, FPS, and object counts.

Counting events are saved in counting_results.csv.
